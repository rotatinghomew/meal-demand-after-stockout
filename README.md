# 售罄之后的供餐需求与备料

这里保存售罄之后的供餐需求与备料工作所用的匿名合成记录。文件不包含分析结果或居民个人资料。

## 资料

`samples/` 中每个文件都是独立的 UTF-8 JSON 文档：`service`、`observations`、`orders`、`supply`、`confirmed_plan`。日期是当地日历日期。空值表示没有对应观测或状态资料，不是数值零。

分钟为当天当地时刻；领取量已包含登记可链接的替代领餐，不能另加到实际售出量。linked_minute 说明该改领并入替代品哪分钟的领取记录。外部团餐订单约束保供，领取只记录现场销售。每份消耗一个共享原料单位。

## 运行

使用 Python 3.11，无需第三方依赖或服务。`python3 inspect_samples.py` 逐个读取资料并列出记录数；`python3 -m unittest discover -s tests -v` 检查关键原始记录间的关系。输出只描述原始资料，不是业务比较结果。
